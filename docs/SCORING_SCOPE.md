# 比賽記錄：支援範圍 【待確認】

任務書要求「先列出要支援的範圍讓我確認，不要一次做完全部」。因為使用者要求一次完成所有階段，下列範圍已先實作；**請確認哪些要保留、哪些要補、哪些要拿掉**。

規則依據：公開的正式棒球規則（Official Baseball Rules）記錄員章節的一般原則。沒有參考任何商用記錄軟體。

## 資料方式
- 每一球（逐球模式）或每一打席（簡化模式）存一筆事件（`game_events`），所有數據都由事件重算，不儲存統計值。
- 任何一筆事件都可以修改或刪除，比分、出局數、壘包與所有數據自動重算。
- 程式：`src/scoring/`（純函式，21 項情境測試）。

## 已支援

### 打席結果
一壘安打、二壘安打、三壘安打、全壘打、四壞保送、故意四壞、觸身球、妨礙打擊、三振（揮空）、三振（站著看）、不死三振上壘、滾地出局、飛球出局、平飛出局、內野高飛出局、高飛犧牲打、犧牲觸擊、野手選擇、失誤上壘、雙殺打、三殺打。

### 跑者
- 每一筆打席結果都記錄每位跑者（含打者）的去向：留在原壘、進到某壘、得分、出局。App 會依結果給預設值（例如保送只推進被迫的跑者），記錄員可以改。
- 打席之間的跑壘：盜壘成功、盜壘失敗、牽制出局、暴投、捕逸、投手犯規、無人防守進壘、失誤進壘、其他進壘、其他出局。

### 換人
代打、代跑（壘上的跑者一起換）、守備調整、換投（被繼承的跑者仍算原投手的責任）。

### 逐球模式
好球（看）、揮空、界外、擦棒、壞球、故意壞球、觸身、打進場內；球種；球數自動累計。四壞或三振時提示記錄結果。

### 數據
- 打擊：出賽、打席、打數、安打、一／二／三壘安打、全壘打、得分、打點、四壞、觸身、三振、高飛犧牲打、犧牲觸擊、盜壘、盜壘失敗、雙殺打、壘打數、打擊率、上壘率、長打率、OPS。
- 投球：局數、面對打者、被安打、失分、自責分、四壞、三振、觸身、被全壘打、用球數、好壞球數、各球種球數、防禦率（9 局制，可改 7 局）、WHIP。
- 守備：刺殺、助殺、失誤。
- 每局得分（線上比分）、殘壘、擊球落點圖。

## 簡化處理（與正式規則可能不同）
1. **自責分**：跑者因失誤或妨礙上壘、或在失誤／捕逸的那一球得分 → 非自責；其他都算自責。正式規則中「若沒有失誤本該是第三個出局」的重建**沒有做**；記錄員可以在每一分上手動改成自責／非自責。
2. **第三個出局的得分**：打者在上一壘前出局（三振、滾地、飛球、觸擊、野手選擇、雙殺）造成第三個出局時，該次的得分不算。其他情況（例如安打後跑者被觸殺成第三個出局）得分照算；時間差（time play）不另判斷。
3. **打點**：預設＝該次得分數，失誤與雙殺不給打點；記錄員可以改。
4. **守備記錄**：依記錄員輸入的守備代號（例如 `6-4-3`、`F8`、`E6`）計算：最後一位刺殺、前面的人助殺；雙殺時倒數第二位也記一次刺殺；三振記捕手刺殺。
5. **一場比賽只有一位記錄員**：兩支手機同時記錄同一場會互相覆蓋（同步採最後修改者勝）。
6. 對手的球員只記名字，不建立帳號。

## 不支援（需要時再做）
- 勝投、敗投、救援、中繼成功。
- 指定打擊（DH）規則的自動處理（可以把 DH 當成一般守備位置填寫）。
- 再上場規則、臨時跑者（tie-breaker 突破僵局制可以手動用「其他進壘」把跑者放上二壘）。
- 抗議、比賽暫停、提前結束（扣分、扣局）的自動判斷；比賽結束由記錄員按「比賽結束」。
- 投手被打擊數的進階統計（BABIP、FIP 等）。
