# Reference data

`obp-ranges.json` is derived from **The OpenBiomechanics Project** by Driveline
Baseball Research and Development
(<https://github.com/drivelineresearch/openbiomechanics>), licensed under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Changes: the 3D joint centres were projected to an ideal side view, the
metrics were computed with this app's analysis engine, and the values were
averaged per athlete and summarised as quantiles. See `docs/REFERENCE_DATA.md`.
